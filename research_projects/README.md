# GRDR research projects

This directory contains question-specific literature evidence, research-indicator hierarchies, and mappings to canonical GRDR variables. These artifacts are deliberately separate from the global source registry.

Each project uses:

```text
<project-id>/
├── project.json
├── literature.jsonl
├── evidence_units.jsonl
├── indicators.jsonl
└── mappings.jsonl
```

Follow `docs/INDICATOR_BUILDER_PROTOCOL.md` and the five indicator-project schemas. Do not commit copyrighted full texts, credentials, sensitive research material, or restricted data.
