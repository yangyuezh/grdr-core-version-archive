# 数据库六层拆解协议

## 目的

数据库进入 GRDR 不能止于名称和主页登记。六层拆解把一个数据源逐步转化为 AI Agent 可检索、可核验、可比较、可连接的研究数据结构：

```text
发布/维护机构 → 数据库/数据源 → 数据集 → 访问资源 → 变量 → 理论构念
```

“GRDR 当前没有登记”只表示注册表覆盖不足，不表示上游数据库不存在相应数据。

## 先声明拆解范围

大型数据库可能包含数百个数据集和数万个变量。每次拆解必须先声明本轮范围：

- `identity_only`：只核验机构和数据源身份；
- `representative_chain`：建立一条代表性的六层链，用于验证结构；
- `question_driven`：围绕一个科学问题优先拆解相关数据集和变量；
- `priority_catalog`：拆解数据库中最重要的一组数据集；
- `catalog_level`：系统枚举官方目录及其主要资源；
- `exhaustive_snapshot`：在特定版本或日期对可枚举内容做完整快照。

存在六层记录不等于数据库已经完整拆解。只有明确范围、枚举方法、上游数量和检查时间后，才能评价某一范围内的完整度。

每个已开始拆解的数据库都必须在 `registry/source_profiles.jsonl` 中保留唯一一条符合 `schemas/source_profile.schema.json` 的当前范围记录。后续轮次更新该记录，历史由 Git 版本保存。该记录持续保存本轮模式、清单完整性声明、各层进度、枚举方法与边界、阻塞条件及复核时间；没有范围记录时，不得推定任何完整度。

## 六层要求

### 第1层：发布/维护机构

识别生产者、发布者、维护者、资助者和治理者，分别记录，不把托管机构自动当作原始生产者。至少核对官方身份、机构类型、管辖范围、主页、职责或授权证据。

### 第2层：数据库/数据源

确定规范名称、别名、官方入口、数据源类型、学科、主题、地理与时间范围、观察单位、数据模态、权威角色、来源位置、访问方式、许可和更新策略。

### 第3层：数据集

从官方目录、数据集页面、API目录或正式文档枚举数据集。每个数据集记录总体、观察单位、空间和时间覆盖、分辨率、版本、更新与修订、方法、限制、引用和证据。

### 第4层：访问资源

登记具体 API、下载文件、查询系统、目录页、云集合、安全环境、申请入口或实体档案。记录格式、身份验证、机器访问、限流、许可和使用条件。

### 第5层：变量

只依据官方字典、代码本、问卷、模式定义、字段元数据或可复现API响应登记变量。记录名称、标签、单位、分母、总体、观察单位、空间和时间分辨率、测量类型、可比性、连接键和证据。

不得根据数据库主题标签推断具体变量存在。

### 第6层：理论构念

把变量映射到研究概念，区分直接测量、自陈、行政测量、传感器测量、构造指数、模型估计、预测、代理变量和潜变量。构念映射必须保留定义、适用范围、证据和不确定性。

## 拆解状态

- `not_started`：该层没有GRDR记录；
- `registered_unverified`：已有候选记录，但没有完成证据核验；
- `registered_with_evidence`：已有至少部分证据；
- `blocked`：受登录、付费、申请、伦理、技术或许可条件阻塞。

来源总体阶段：

- `source_only`：只有机构和数据库层；
- `dataset_depth_started`：数据集或资源层已经开始；
- `variable_depth_started`：已有变量，但六层链尚不完整；
- `six_layer_chain_present`：至少存在一条六层链，但不代表完整枚举。

## 标准执行流程

1. 搜索 GRDR，避免重复登记同一数据库。
2. 运行 `python3 scripts/grdr.py audit-source-depth <source-id>`。
3. 声明本轮拆解范围和停止条件，并写入或更新 `registry/source_profiles.jsonl`。
4. 优先使用官方机构、目录、方法、字典、API和许可文件。
5. 按六层顺序写入规范 JSONL 记录和关系。
6. 未知字段保持未知；冲突证据并存并标记。
7. 运行注册表验证、目录生成和六层深度审计。
8. 报告新增记录、证据、未解决层级、访问限制和下一轮范围。

## 每轮完成条件

一轮拆解只有在以下条件同时满足时才完成：

- 本轮范围已声明；
- 新增或修改的记录通过Schema和引用完整性验证；
- 每项提升验证状态的声明都有适当证据；
- 人类目录与结构化注册表同步；
- 未覆盖内容和阻塞条件明确列出；
- 没有把代表性样本误报为完整数据库清单。
